## 追加で確認した制約・失敗

1. 公式バスナビの利用条件は、自動化されたコンテンツ収集・解析・再配信等を禁止しています。30秒間隔のクローラー、公開JavaScriptからの内部API探索、Cookie等を用いた403回避を実装していません。[利用条件](https://transfer-cloud.navitime.biz/keiseibus-group/terms-of-use)
2. ODPTのCKAN互換を想定した `/api/3/action/package_search` はJSONとして解釈できませんでした。調査結果は実際に返った公開検索ページに基づき、この経路を利用可能なAPIとして提案していません。
3. ODPTの公開静的ファイルURLはHTTP 302で署名付きBlob URLへ移動し、その転送先への接続は環境側で403でした。同じ対象外GTFSはリポジトリの正式公開経路から取得できたため、元の経路を無理に再試行していません。これはデータの不存在を意味しません。署名付きURLは同梱していません。
4. GTFSリポジトリのAPI仕様・規約文書のHTTPSは503／タイムアウトでした。サイトが案内するHTTPの公開文書は取得できました。規約PDFは画像のため、3ページを画像表示して第5条等を確認しました。実データAPI通信はHTTPSです。
5. カタログの一部応答がgzip形式だったため、展開してJSON解析しました。証跡の`decoded_body_sha256`は展開後の本文に対する値です。

## 再現方法

Python 3.10以上、標準ライブラリのみで実行できます。

```bash
# ドキュメントにある3つの公開メタデータAPIに各1回GETする
python scripts/phase0_verify.py --catalog --output work/catalog-verification.json

# 利用許諾を確認して取得したローカルZIPをオフラインで検査する
python scripts/phase0_verify.py --gtfs work/feed.zip --output work/gtfs-verification.json
```

`--catalog`の有効日フィルターは本調査日の`2026-11-08`に固定しています。後日再調査するときは日付と調査報告を更新してください。実ファイルURLは返却されたメタデータを確認して選択し、対象外のファイルを対象路線の運行データとして採用しないでください。

スクリプトは公式バスナビへアクセスしません。外部API失敗・不正なZIPは失敗終了し、「空の検索結果」や「運行なし」とは扱いません。カタログの正常終了でも、対象路線が利用可能とするフラグは立てません。
